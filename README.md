
# Integration Lab

A hands-on learning repository for understanding integration through mathematics, programming, and real-world computer science applications.

## About

Integration Lab is designed to help learners connect calculus with programming.

Instead of only memorizing formulas, we focus on understanding mathematical concepts, translating them into program logic, and building practical projects.

The learning track progresses gradually from beginner-level tasks to more advanced applications.

## What This Repository Covers

- Mathematical function evaluation.
- Antiderivatives and indefinite integration.
- Function reconstruction using initial conditions.
- Motion and state modeling.
- Simulation and collision detection.
- Polynomial integration systems.
- Connections between calculus and computer science.

More learning tracks may be added in the future.

## Languages

## Learning Philosophy

> Understand the mathematics. Translate it into logic. Build something with it.

Each learning track is divided into projects with increasing difficulty.

Learners are encouraged to:

1. Understand the mathematical concept.
2. Solve problems on paper.
3. Implement the logic in code.
4. Test the implementation.
5. Reflect on what they learned.

## Reference Solutions

Reference solutions are stored in:
